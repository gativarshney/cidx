# Support

cidx is pre-alpha and under active development by a solo maintainer.

## Getting help

- **Bug reports and feature requests:** open a
  [GitHub issue](https://github.com/gativarshney/cidx/issues) using the matching
  template. For bugs, include your OS, Python version, and cidx version
  (`cidx --version`).
- **Questions:** open a blank GitHub issue. There is no chat server or mailing
  list, and none is planned before the first release.

## What to expect

Issues are triaged on a best-effort basis. The project is developed in phases
(see [MILESTONES.md](MILESTONES.md)); reports that affect the current phase are
handled first. A firmer support cadence will be written into this file at the
first release.

## Security

There is no code that runs against untrusted input yet. Once the MCP server
exists, security reports should be sent by email to the maintainer rather than
filed as public issues; this section will be updated with details at that point.
